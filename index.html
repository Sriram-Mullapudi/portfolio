02 /

Speedway POS

An offline-first checkout built for everyday retail.

Commit the sale locally.

The register sends checkout operations to Rust. Atomic SQLite writes keep the sale consistent when the network is unavailable.

0 duplicate charges

Observed in 10,000+ test attempts across 20+ failure and concurrency scenarios.

View repository ↗
Architecture & validation

React · TypeScript · Rust / Tauri 2 · SQLite

Atomic SQLite operations, role-based access, Argon2 PIN hashing and an append-only audit log support financial workflows.

Used with a 10K+ SKU catalog and 5K+ real-world sales.

Offline operation keeps checkout available; transaction integrity stays local to the register.
